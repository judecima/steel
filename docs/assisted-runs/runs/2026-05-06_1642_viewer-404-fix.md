# Fase 9B.Fix — Corrección de 404 en Visualizar

## Objetivo
Eliminar el error 404 al acceder a `/proyectos/[id]/viewer` asegurando que el visor legacy se cargue correctamente dentro del ecosistema Next.js.

## Cambios Realizados

### 1. Migración de Activos Estáticos
- Se creó la carpeta `apps/product-ui/public/qa-viewer/`.
- Se sincronizaron los archivos `index.html`, `viewer.js` y `localizacion.js` desde `tools/qa-viewer/`.
- Esto permite que Next.js sirva el visor bajo la ruta `/qa-viewer/index.html`.

### 2. API de Renderizado Dinámico
- **Nuevo Endpoint**: `GET /api/proyectos/[id]/render`
- Este endpoint utiliza el `SceneBuilder` para generar el `RenderSceneIndustrialDTO` directamente desde la base de datos PostgreSQL, eliminando la dependencia de archivos JSON estáticos en disco.
- Maneja fallbacks para proyectos que aún no tienen resultados de motor, evitando errores fatales en el visor.

### 3. Refactorización del Visor Legacy (`viewer.js`)
- Se actualizó la lógica de carga para detectar el `projectId` desde la URL del iframe (`?id=...`).
- Se redirigió la carga de datos hacia el nuevo endpoint `/api/proyectos/[id]/render`.
- Se actualizaron los botones de descarga industrial para apuntar a la API de exportaciones segura: `/api/exports/[id]/[archivo]`.

### 4. Mejoras en la UI de Next.js (`page.tsx`)
- Se actualizó el `src` del iframe para apuntar a `/qa-viewer/index.html`.
- Se agregó un `overlay` de error/fallback para mejorar la experiencia del usuario si los activos no están presentes o el proyecto falla al cargar.

## Verificación Exitosa
Se ejecutó la suite de pruebas `scripts/next_product_ui_tests.ts` con los siguientes resultados:
- **TEST V1**: iframe apunta correctamente a `/qa-viewer/index.html`.
- **TEST V2-V3**: Archivos físicos existen en `public/qa-viewer/`.
- **TEST V4**: Se eliminaron todas las referencias a rutas relativas fuera de `public`.
- **TEST V5**: Integración de `postMessage` confirmada para cambios de modo.
- **TEST V6**: Fallback visual configurado.

## Validación Manual Recomendada
1. Acceder a `http://localhost:3002/proyectos/[id]/viewer`.
2. Confirmar que el visor 3D carga el modelo.
3. Probar los modos "Taller" y "Ingeniería" para verificar que los metadatos dinámicos se visualizan correctamente.
4. Intentar descargar un BOM desde el panel del visor y confirmar que se descarga el archivo del proyecto correcto.
