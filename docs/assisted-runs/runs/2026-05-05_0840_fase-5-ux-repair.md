# Run Report: Fase 5 — Reparación UX y Descargas
Fecha: 2026-05-05

## Objetivo
Resolver bloqueadores críticos en la experiencia de usuario del visor de QA, asegurando que las exportaciones industriales sean descargables y que los controles de visualización ("Aislar" y "Enfocar") funcionen correctamente sin interferencias de interacción.

## Causa Raíz
1. **Click-through**: El listener de `pointerdown` en el objeto `window` no discriminaba entre clics en la escena 3D y clics en elementos de la interfaz (botones). Esto causaba que, al intentar pulsar un botón de control, el sistema deseleccionara el objeto actual si no había nada detrás del botón en la escena 3D.
2. **Rutas de Descarga**: La resolución de rutas relativas para las descargas era sensible a la presencia o ausencia de la barra inclinada final (`/`) en la URL del navegador, causando errores 404.

## Cambios Realizados

### 1. Visor de QA (tools/qa-viewer/viewer.js)
- **onPointerDown**: Se implementó una guardia de protección para ignorar eventos que se originen en elementos de la UI (`#ui-panel`, `#selection-panel`, botones, selects e inputs). Esto elimina el problema de deselección accidental.
- **Download Logic**: Se refactorizó la construcción de `baseUrl` para que sea robusta e independiente de cómo se acceda a la URL del visor.
- **Aislar Capa**: Se mejoró la lógica para asegurar que todos los objetos de la escena (incluso los que no están en grupos de capas) sigan el estado de visibilidad del aislamiento.

### 2. Panel de Exportaciones (tools/qa-viewer/index.html)
- Se añadió un bloque visual dedicado a "Exportaciones Industriales" con botones de descarga directos.

### 3. Scripts de Automatización
- **export:industrial**: Nuevo script que genera físicamente los activos industriales en la carpeta `exports/` del visor para permitir descargas reales.

3. El aislamiento de capas oculta correctamente todos los elementos no deseados.
